Selected Projects

jvm-triageJava

Offline analyzer for JVM heap and thread dumps. Point it at a dump and it names what is holding memory or which threads are deadlocked — single jar, no agent, no GUI.

Byte-level parser written from the HPROF binary format specification. Retained-size attribution via a dominator tree; deadlock detection by cycle-finding on the thread wait-for graph, catching cycles the JVM's own deadlock banner misses. Every synthetic test passed until the first real dump broke it two ways — static fields were not treated as GC roots, which hid the single most common Java leak.

rack-sentinelGo

Predictive hardware failure detection from server fleet telemetry over Redfish. Ranks DIMMs by correctable-error trend and acceleration rather than raw count.

A flat 11,000-error DIMM is ECC doing its job; a 200-error one that doubled this week is about to take the node down. Least-squares rate with confidence scoring and power-cycle counter-reset handling. A counter the BMC did not report is recorded as absent, never zero — coercing it would make a blind controller look like healthy hardware.

Open-Source Contributions

gitleaks28k ★ · secret scanner · GoPR #2227 — open

A scan returned clean and I did not believe it. A planted-secret test showed an allowlist configuration was causing matching files to be skipped during enumeration before they were ever read — so real secrets in them went unreported while the tool reported success. Root-caused a disagreement between the enumeration and detection layers. The fix preserves existing behavior and ships with a table-driven regression test.
