# Basit Developer Portfolio

Welcome to my personal developer portfolio! This website is designed to showcase my projects, skills, and professional experience. It also includes a downloadable resume and a contact form for potential employers, clients, and recruiters to get in touch.

## Features

- **About Section**: Learn more about me and my expertise in web development.
- **Projects Section**: Explore my portfolio of projects, highlighting key features and technologies used.
- **Resume**: Download my professional resume directly from the website.
- **Contact Form**: Reach out to me easily using the integrated contact form.
- **Interactive Features**:
  - Smooth scrolling for seamless navigation.
  - "Back to Top" button for easy navigation.
  - Dark mode toggle for a personalized viewing experience.

## Technologies Used

- **HTML5**: For structuring the content.
- **CSS3**: For styling and responsive design.
- **JavaScript**: For interactivity and dynamic features.

## How to View

1. Clone this repository:
   ```bash
   git clone https://github.com/BasitS-hash/basit-developer-portfolio.git
   ```
2. Open the `index.html` file in your browser to view the portfolio locally.
